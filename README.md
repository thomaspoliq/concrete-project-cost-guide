# The True Cost of a Concrete Project: A Complete Budget Guide

A project level budgeting guide to everything a concrete job costs beyond the concrete itself: delivery and short load fees, pump hire, sub base and compaction, formwork timber, reinforcement, finishing tools, sealer and waste disposal, all built into a worked example budget for a typical driveway. Prices are typical approximate UK ranges for planning, not quotations.

## Deploying this page

The finished page is `index.html`, a single self-contained file with no external assets. It can be deployed as a static site (GitHub Pages, Vercel or Netlify) or served through the included Streamlit app (`app.py`, needs `streamlit` from `requirements.txt`).
